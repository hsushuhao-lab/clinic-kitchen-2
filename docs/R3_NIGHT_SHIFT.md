# R3 晚班挑戰・精準加分・動態配樂

## 目標與範圍
上方保留 R2 三位 Q 版全身醫師、連續診間、走路／跑步／端餐、家具碰撞及手機控制。下方保留麻婆豆腐的取材、切配、炒鍋、配飯與送餐。這一輪改善可重玩性與緊張節奏，不重畫人物、不改成導航圖、不加第二道菜。

## 新玩法
預設是練習模式，原本 craving 速度和選角能力不變。確認問診前按「晚班挑戰」切換成連續三單：

| 單數 | 指定口味 | 準時目標 | Craving 速率倍率 |
|---|---|---|---|
| 1 | 正常辣／不要蔥／半碗飯 | 90 秒 | 1.00 |
| 2 | 重辣／要蔥／正常飯 | 80 秒 | 1.15 |
| 3 | 正常辣／要蔥／半碗飯 | 70 秒 | 1.30 |

挑戰口味由病人指定，問診時顯示並鎖定；不再由玩家任意調成最簡單規格。這三種訂單皆能以現有食材達成。計時從確認處方開始，閱讀對話、暫停和隱藏分頁不計時。目標逾時只失去準時賞金；Craving 到 100% 才是本單失敗。

白色游標進入綠色區操作可得 GOOD，金色中央得 PERFECT。用滑鼠／觸控原操作鈕，或在工作站按 Space。切配及核心食材全部下鍋後的前三次翻炒可加分；沒命中仍正常推進料理，不設 timing 硬卡關。連擊達 3／6／9 次時，技巧得分倍率為 1.25／1.5／2，最高 2 倍。重複已完成動作不加分；220ms 內連點不中精準分。

每張訂單增加的分數：技巧分 + 準時分（剩餘秒數 × 2 後向下取整；品質至少 80）+ 完美訂單 40 分。準時要求只在晚班使用。結果顯示 S/A/B/C、各加分來源、最高連擊、三單總分。本機紀錄只在完整完成三單後儲存；不需登入、不傳送玩家資料。

放棄或失敗後重新開始晚班第一單，已獲得的原本總分依 R2 行為保留。完整三單結束後按「再挑戰一個晚班」清除本班狀態。

## 料理選擇與公平性
收汁完成後現在可以先關火、去盛飯，再回來盛盤；已完成收汁的料理不需要重新開火才能裝盤。爐火持續開著仍會過火。提示顯示距離過火的秒數，玩家可以選擇冒險拚快，或先關火安全處理配飯。

精準加分不改變醫師被動能力、不額外扣品質、不用靜音懲罰玩家。判定以遊戲時鐘計算，不以聲音能否播放決定；視覺游標是精準目標，不宣稱逐拍音遊。

## 原創配樂與聲音
`src/adaptive-audio.js` 用原創音符序列、合成音色和程式化打擊樂生成配樂，不使用他人歌曲、錄音、網路音源或麥克風。

輕快 96 BPM → 忙碌 120 BPM → 衝刺 144 BPM。忙碌狀態增加節奏層；Craving 高、最後 15 秒或快過火時進入衝刺。變化靠速度及配器，不是突然提高總音量。出票、操作判定、收汁完成、警示、勝利與失敗有不同提示。

第一個玩家手勢之後才建立 AudioContext。M 或「音樂」按鈕靜音，音量可調，設定在允許儲存時保留。只有一個 AudioContext 和 scheduler，暫停／選角／背景分頁停止排程；讀對話降低伴奏音量；勝敗播放短提示，不繼續高壓伴奏。瀏覽器禁止音訊時仍可無聲遊玩。

API 行為參考：MDN Web Audio best practices（https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices）及 Autoplay guide（https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay）。

```sh
node --test tests/shift_rules.test.cjs tests/rush_rules.test.cjs
python tools/build_web_release.py
python -m http.server 8000 --bind 127.0.0.1 --directory web-dist
python tests/test_rush_game.py --base-url http://127.0.0.1:8000/ --output qa/current/rush --preview
```

新的純規則測試包含 timing 邊界、重複／連點防刷分、分數結算、三單進程、逾時不立即失敗、品質門檻、壓力倍率與重來。新的瀏覽器測試由實際鍵盤／點擊連續完成三單，不直接改任務階段或傳送人物；另驗證音訊非零能量、靜音／暫停、單一 scheduler、末段 144 BPM、四種畫面大小與完整晚班結果。

`--inline` 僅代表離線瀏覽器，以當次 source/asset bytes 替代 URL；不代表 HTTP 或部署成功。CI 從真正 HTTP runtime 執行，通過才部署 Pages。公開部署再比對相同 SHA 與所有檔案。

測試證明功能成立，不代表所有玩家已確認好玩。這一版仍是可玩 2D Q 版遊戲，不宣稱角色或場景已成為 3D 寫實模型。遊戲設定不代表麻婆豆腐具有戒菸療效。
