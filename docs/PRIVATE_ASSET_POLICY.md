# 私人素材政策

真人參考照片、來源聯絡拼圖、歷史產物／舊ZIP／舊QA，全部在另份 `clinic-kitchen-2-private-history-r2.zip`。此封包不是公開網站與 repo 的部署材料。

本 source repo 不含私人照片；.gitignore 亦排除 private／archive 路徑。這不代表可以隨意公開歷史 Git bundle，因為前一版 bundle 曾把私人照片與舊 ZIP 收入同一歷史。本輪新 bundle 僅由本 source tree 建立。

以精確素材雜湊追溯來源；未取得相應同意之前，不把私人影像上傳到公開 repository。部署靜態網站須逐項列入 runtime 需要檔案，不能直接發布含私人目錄的整包。
