# 從這裡開始

R2 是整合與修復版本，不是美術封版。

1. README.md：執行／測試／發布。
2. docs/CURRENT_STATUS.md：已實作與未實作的明確界線。
3. docs/DESIGN_SPEC.md：最新規劃，優先於舊設定。
4. art-review.html + assets/manifest.json：七张完整原稿與素材雜湊。
5. docs/AGENT_PROMPT.md：下一個 AGENT 的可驗證任務。
6. docs/MIGRATION_LOG.md：來源、包裝與遠端發布狀態。

新 repo root 的程式位於 src/main.js；舊 repo 對應 CK/src/main.js。不可混用兩種路徑。
