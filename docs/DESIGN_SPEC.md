# 最新遊戲設計規格

## 核心
精緻、偏寫實的診間料理模擬。前半是真實診間，中間為清潔／備料過渡區，後半是固定存在且可走入的後廚。三區空間連續；不是切換一張背景，也不是診間魔法变成餐廳。

## 上下版面
上方：主角移動、診間／過渡區／廚房探索與任務交互。下方：食材、砧板、刀具、炒鍋、料理狀態與盛盤。兩區需同屏可見；低高度或手機允許下方獨立捲動，不把整個遊戲頁面擠出首屏。此 UI 結構不代表要求上下都用 CSS 畫圖；後續可在此結構內放真正 3D 場景與工作站鏡頭。

## 人物
以核准圖中的三個虛構可選角色為準，不把真人姓名或能力推論進設定。DR. SPEED：透明框眼鏡、短黑髮、白袍、淺色內搭，動作俐落；DR. HEAT：細框眼鏡、藍襯衫、白袍，火候操作為特色；DR. STRATEGY：圓框眼鏡、米色內搭、白袍、綠口罩元素，以對話與規劃為特色。
三人皆使用真實成人比例。每人獨立交正面、背面、左右側、前後 3/4；獨立表情圖；統一尺度、光線、相機焦距與服裝細節。不得由合成總海報硬裁後宣稱完成 turnaround。建模稿、網格、骨架、貼圖與遊戲內截圖分別交付。

## 空間與道具
診間：醫師桌、電腦、鍵盤、電話、印表機、病人椅、醫師椅、醫療抽屜、洗手台、衛教告示與診間入口。
過渡區：洗手、圍裙、更換工作器具、食材冰箱、不鏽鋼推車、料理處方單。
後廚：不鏽鋼備料檯、砧板、刀、調味架、黑色炒鍋、爐具、排煙、飯鍋、盛盤與清洗區。比例必須可供角色走動，碰撞不得封死走道。前區冷白照明、後區較暖照明；不是用巨型文字標籤代替空间辨識。

## 第一條完整任務
病人入座 → 主角問需求 → 寫料理訂單 → 列印 → 走過過渡區 → 從冰箱／櫃子取材 → 切豆腐與蔥蒜 → 開火與料理 → 盛飯／盛菜 → 托盤端回 → 病人第一口 → 反應與結算。
先完成一位主角、一位病人、一碗麻婆豆腐。這條鏈驗收前不擴第二道料理、多人模式或更多病人。

## 食譜機制（待實作）
熱鍋、加油、絞肉炒散與變色、豆瓣醬與蒜／豆豉爆香、豆腐與高湯燉煮、少量澱粉水勾芡、花椒與蔥、白飯與盛盤。重點是實際可見且可操作的食材狀態，不再串接多條 timing bar。烹飪順序需在開發中以一份凍結食譜資料表統一，不讓美術與程式各寫一套。
